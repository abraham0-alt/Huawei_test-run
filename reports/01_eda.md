Generated by `python scripts/01_eda.py` (seed 42). Metric: ROC AUC pooled over all rows.

## Key findings

- Train has 6,868,240 rows / 686,824 events / 53,003 users / 50,000 items; every event has exactly 10 unique items and 0 events have more than one click.
- Row click rate is 6.29% (432,023 clicks); 37.10% of events have zero clicks (allowed).
- time_bucket matches 6-hour UTC blocks with 0 mismatches; day_type matches weekend/weekday with 0 mismatches. Docs agree with the data.
- Evaluation is 52,939 events for 52,939 users (one event each). 1,453 eval users (2.74%) never appear in train; 0 eval items are unseen.
- A leak-free item-CTR predictor scores ROC AUC 0.5288 on the Jan 25 first-event fold and 0.5244 on the Jan 26 fold — item popularity is a real but limited ranking signal.
- Candidates that appear in the user's history click at 29.31% vs 5.68% when they do not (2.59% of impressions are repeats).
- Empty history: 0.33% of train events and 1.26% of eval events. 76.30% of train histories repeat an item.
- Eval is a first-event-after-cutoff sample, so it is front-loaded in time (not a typical train day mix). Fold files are the same protocol applied at 2025-01-25 and 2025-01-26, not full calendar days.
- rowid / file order within an event is effectively uninformative (CTR spread 0.0009 by rowid rank, 0.0008 by scan order); do not use rowid as a feature.
- Cold start in eval vs all train: 2.74% of rows are unseen users, 1.26% empty history, 0.00% unseen items.

## Recommended features and risks

- **Use:** item prior CTR (time-aware), `time_bucket`, hour, `day_type`, history length, whether the candidate is in history, recency of that click, gap since last click, user activity (events so far before the cutoff).
- **Use carefully:** user CTR — many eval/fold rows are a user's first post-cutoff event, so user averages from the same period leak and post-cutoff user counts are tiny.
- **Do not use:** `rowid` or `event_id` as numeric features; in-fold labels; any aggregate computed on the scored rows.
- **Risks:** eval is Monday-morning-skewed vs train's evening-heavy mix; ~2–3% brand-new users; empty histories are more common in eval than a typical train event. Item-CTR alone will not win — history match/recency is a stronger row-level signal. Folds that copy the first-event protocol are closer to the leaderboard than random or full-day splits.
